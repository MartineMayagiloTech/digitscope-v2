# DigitScope V2 — Matches/Differs Lab

Version 2 adds:
- Matches-specific and Differs-specific signal ranking
- 100/500/1000 tick lookback
- Signal threshold
- Digit distribution, streaks, entropy and balance
- Live signal journal
- Historical tick loader
- One-tick MATCH/DIFFERS backtesting
- Win rate, losses, max losing streak and simplified model P/L
- Equity curve
- Saved performance dashboard
- PWA shell

## GitHub Pages
Upload all files to the repository root. In Settings → Pages choose GitHub Actions or branch deployment. The included app is static and can use Deriv public market-data WebSocket from the browser.

## Important
The backtest P/L is simplified and does not model actual Deriv payout. This tool does not guarantee predictions or profits. It does not place trades or store account credentials.
